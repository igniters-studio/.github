# igniters

English · [Français](https://github.com/igniters-studio/.github/blob/main/profile/README.fr.md)

A solo studio that builds mobile apps, SaaS and the tooling that goes with them, in public.
igniters signs; each product keeps its own name.

## Open source

**[AREA Framework](https://github.com/igniters-studio/area-framework)**: a tracking framework for
mobile apps that starts from business goals, not from events. Four pillars every mobile app shares,
a reference KPI for each, and the minimum tracking that makes them readable.
[Website](https://igniters-studio.github.io/area-framework/)

## Tooling

**supertrack**: a paid tool that audits an app's tracking from its codebase and checks it on
every pull request, against AREA.
